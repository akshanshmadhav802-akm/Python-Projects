# 🐍 Python Beginner Projects

A collection of small Python projects I built while learning Python from the fundamentals.

This repository documents my journey from understanding basic Python syntax to building small, functional programs using **lists, loops, conditions, user input, and basic problem-solving**.

> 🚀 **Learning by building — one project at a time.**

---

## 📚 About This Repository

I created this repository to practice Python concepts through hands-on projects rather than only following tutorials and examples.

The projects are intentionally beginner-friendly and focus on understanding the **logic behind the code**.

As I learn new Python concepts, I will continue adding more projects and improving the existing ones.

---

## 🛠️ Projects

### 1. 🎓 Student Marks Calculator

A simple program that stores students and their marks and allows the user to check a student's performance.

**Features:**

- Search student by name
- Display subject marks
- Calculate total marks
- Find highest marks
- Find lowest marks

**Concepts Practiced:**

- Lists
- `if / elif`
- `for` loops
- `input()`
- `max()`
- `min()`
- Accumulator variables
- Basic conditional logic
